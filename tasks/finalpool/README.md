# Final Pool

This directory contains the final pool of implemented tasks from BenchTasksCollv3.
Tasks are added here after they pass validation:
- task_config.json with non-empty needed_mcp_servers and needed_local_tools containing "claim_done"
- docs/task.md non-empty and in English
- docs/agent_system_prompt.md non-empty and in English
- docs/user_system_prompt.md (optional, but if present must be in English)

As of the latest audit, no tasks in the developer branches satisfy all requirements
(all are missing task_config.json), so this pool is currently empty.
