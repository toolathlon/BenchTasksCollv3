# Finalpool

This directory is the integration pool for `BenchTasksCollv3`: every task here is a
copy of a task from a developer branch (`tasks/<developer>/<task>`) that was
reviewed and judged **implemented** against the template in `tasks/examples/example-task`.

See `TASK_TRACKER.md` for the full list with ownership and status.

The 22 tasks from the most recent developer commits are all in the finalpool branch
under `tasks/finalpool`, together with 5 tasks integrated earlier.
